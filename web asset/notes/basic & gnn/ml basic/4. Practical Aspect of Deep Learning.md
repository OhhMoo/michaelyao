### **Regularization**
#### L2 Regularization
To address overfitting (reduce variance)
In formula: $$ J(w,b) = \frac{1}{m} \sum_{i=1}^{m}L(\hat y^{(i)}, y^{(i)}) + \frac{\lambda}{2m}||w||^2_2$$

Where the W squared are addressed as:
**Frobenius Norm**
$$||w^{[l]}||^2_F = \sum_{i=1}^{n^{[l]}}\sum_{j=1}^{n^{[l-1]}} (w_{i,j}^{[l]})^2$$
As a result, we update the $dw^{[l]}$:

##### Why Regularization Reduces Overfitting

As shown, if we take a large $\lambda$, the cost function will be huge, and the weight will be penalized severely, thus keep the weight being small. (Covert a non-linear function to behave linearly)

#### Dropout Regularization
![[Pasted image 20260105211702.png|400]]
##### Implementing dropout 
**"Inverted Dropout"**
![[Pasted image 20260105212019.png|400]]

```python
keep_prob = 0.8 #The ratio of the neuron remains
a3 /= keep_prob
```
##### Understanding Dropout
Intuition: Can't rely on an one feature, so have to spread out weights --> This will shrink weights (Prevent overfitting)
![[Pasted image 20260105224036.png|400]]
For the layer that we want to keep more info (like $n^3$), we'd like to set keep_prob = 1, but with multiple neurons, we can set it to be 0.7 or even lower.

Dropout is always being used in computer vision: prevent overfitting since computer vision has too much information.

#### Normalize the input
![[Pasted image 20260105230413.png|400]]
1. Subtract Mean: $$\mu = \frac{1}{m}\sum_{i=1}^{m}x^{(i)}$$
	Where $x := x-\mu$ , centered around 0

2. Normalize Variance: $$ \sigma^2 = \frac{1}{m}\sum_{i=1}^{m}(x^{(i)})^2$$
	Where $x = \frac{x}{\sigma}$, makes scale to 1

##### Why normalize input?
![[Pasted image 20260105225946.png|400]]
Create a symmetric (similar scale) cost function; easier to optimize.
