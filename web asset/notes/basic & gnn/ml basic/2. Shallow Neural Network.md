### Activation Function

$$ a = tanh(z) = \frac{e^z-e^{-z}}{e^z+e^{-z}}$$
This will work better for most of the cases than sigmoid function. Because it is centered around zero.

### Random initialization
If we take all the input matrix as zero for the hidden units, the same row of the matrix will lead to generating same weight on $w^{[1]}_1$ and $w^{[1]}_2$. 
![[Pasted image 20260102164908.png|400]]

So... We need to initialize our matrix. 
```python
w_1 = np.random.randn(2,2)*0.01
b_1 = np.zeros((2,1))
```
keep b values as zero will be fine, but not w.
