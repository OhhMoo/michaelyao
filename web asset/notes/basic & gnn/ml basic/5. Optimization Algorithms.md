#### Notation: $$X^{\{T\}}, Y^{\{T\}}$$
Process a single x{T} for T from 1 to 5000, instead of running 500,000 samples.

- Choose the size

	Make sure the minibatch fit into CPU/GPU memories.


### Exponentially Weighted Averages
It is finding the moving average, or the exponentially weighted averages. 
eg. Weather in London
![[Pasted image 20260117225244.png|400]]
#### $$v_t = \beta v_{t-1} + (1-\beta)\theta_t$$
We can take it as "$V_t$ is approximately averaging over $\frac{1}{1-\beta}$ days"
![[Pasted image 20260117225526.png|400]]

**Key Understanding**
![[Pasted image 20260120185442.png|400]]

**Implement Exponentially weighted averages**
![[Pasted image 20260120185733.png|400]]
In code, we are basically keep repeating the part  
	{
		get new $\theta$ and get new $v_t$
	}

#### Bias Correction
Used to prevent moving average starts off very low at the begining of the iterations.
Since we starts with $v_0 = 0$, the first few terms will be pull down.
$$\hat v_t = \frac{v_t}{1-\beta^t}$$
