### **Vectorization** 
Whenever possible, avoid explicit for-loops
For Logistic Regression:
$$ [z^{1},z^{2}...z^{m}] = w^T \cdot X + [b,b...b]$$
$w^T$ will become a row vector, and it dots with $X$ compiled in columns, and formed the $Z$ (a row vector with multiple z).
```python
Z = np.dot(w.T, X)+b
```
Then we put $Z$ into the sigmoid function and return a row vector of $A$ (The prediction of all the $\hat{y}^{(i)}$, or we call it as activation matrix)

From the previous image, we know $dz^{(i)}=a^{(i)}-y^{(i)}$ 
Therefore, $dZ = A-Y$
![[Pasted image 20251230134035.png|400]]
```python
dZ = A-Y
db = (1/m)*np.sum(dZ)
dw = (1/m)*np.dot(X,dZ)

w := w-lr*dw
b := b - lr*db
```
