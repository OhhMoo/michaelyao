### Deep Neural Network Notation
- $n^{[1]}$ is the number of neuron in the first hidden layer.
- $a^{[1]}$ is the activation matrix in the first hidden layer.
- This is calculated by $a^{[l]} = g^{[l]}(z^{[l]})$, and $w^{[l]}$ is the weight

### Forward Propagation
First:
$$ Z^{[l]} = W^{[l]}\cdot A^{[l-1]} + b^{[l]}$$
Second: 
$$A^{[l]} = g^{[l]}(Z^{[l]})$$

There is a for loop we cannot avoid, the for loop from 1 layer to the next layer.
